# Telegator — цели, решения, очередь

## Цель

Свой клиент Telegram для владельца и сотрудников (macOS + Windows):

1. Боковая панель Telegator в окне чата и немногие кнопки действий.
   Действие выполняет сервер владельца; клиент только сообщает «нажали X в чате Y».
2. Фичи, которых нет в официальном клиенте (список ниже).

## Принятые решения (не пересматривать без нового основания)

| Решение | Почему |
|---|---|
| База — чистый `telegramdesktop/tdesktop` | один код на macOS и Windows |
| Готовый форк (AyuGram) за основу не берём | взять нужное ≈ 2 900 строк; выпилить лишнее ≈ 25 800 строк + зацепки в 134 файлах Telegram |
| Наш код — в отдельной папке, в файлы Telegram — точки вызова | дешёвые обновления |
| Сборка — GitHub Actions, репозиторий публичный | бесплатные macOS/Windows-машины; GPL выполняется |
| Приложение будет переименовано в Telegator | нельзя использовать имя/логотип Telegram; бонус — ставится рядом с официальным клиентом |
| Встроенное автообновление выключено | иначе Telegram заменит форк официальной сборкой |
| Контент с таймером не сохраняется никогда | п. 1.4 условий Telegram API |
| Обход защиты от копирования — делаем | в условиях API не упомянут; риск принят владельцем |
| Основной интерфейс — боковая панель справа: веб-страница с сервера владельца во встроенном webview | содержимое (профиль клиента, админка, подсказки нейросети) часто меняется — меняем страницу на сервере без пересборки и раздачи клиента |
| Панель — только для аккаунта обменника; какой это аккаунт и адрес страницы — в локальном конфиге | бизнес-специфика вне репозитория |
| Нативные кнопки в самом клиенте — только немногие стабильные | каждое изменение клиента = сборка и раздача |
| Сотрудникам раздаём после базовых фич (владелец 21.09.2026) | раздавать пока нечего |

## Сделано

- PoC: кнопка `TEST` в поле ввода отправляет фиксированный текст штатным
  механизмом отправки. Проверено владельцем в собранном клиенте.
- Репозиторий, облачная сборка macOS (Debug), кеш библиотек, секреты API.
- Модуль `telegator/` (`Telegram/cmake/telegator.cmake`); PoC-кнопка —
  `telegator/telegator_compose_buttons.*`, в `history_widget` — точки вызова.
- Переименование в Telegator: имя, bundle id `io.github.kdedushev.telegator`,
  папка данных, AppId, AppUserModelId; ссылки `tg:` и ярлык Windows остаются
  за официальным клиентом. Проверено в сборке рядом с Telegram Desktop.
  Иконки пока от Telegram.

## Очередь

1. **Иконки Telegator** — свои вместо логотипа Telegram (нужен рисунок).
2. **Панель Telegator (PoC)**: панель справа от чата со значком в шапке,
   внутри webview (`lib_webview`, как мини-приложения ботов) грузит тестовую
   страницу; клиент передаёт странице открытый чат; мост страница→клиент —
   одно действие «вставить текст в поле ввода» (отправляет сотрудник).
   Показывается только для аккаунта из локального конфига.
3. **Договор панели с сервером**: вход сотрудника и права на данные клиентов,
   откуда сервер берёт переписку для подсказок (передаёт клиент или свой
   сервис), список действий моста; для действий на сервере — защита от
   двойного нажатия (idempotency key), журнал, исходы
   «принято / отказано / неизвестно», отзыв конкретного устройства.
4. Наполнение панели на стороне сервера: профиль клиента, админка, подсказки
   нейросети (заготовка, расчёт). Делается вне этого репозитория.
5. Показ числового ID в профиле (~17 строк, образец — AyuGram).
6. Подтверждение перед исходящим звонком: одна точка
   `Calls::Instance::startOutgoingCall`; показать один раз, различать
   аудио/видео, не повторять после диалога разрешений микрофона.
7. Обход защиты от копирования: `PeerData::allowsForwarding()` и
   `HistoryItem::forbidsForward()`; поправить места, где эти функции
   показывают состояние в настройках (`boxes/peers/edit_peer_info_box.cpp`,
   `window/window_peer_menu.cpp`).
8. Поиск по числовому ID (~60 строк, образец — AyuGram `searchUserById`).
9. Сохранение удалённых сообщений (образец — AyuGram `ayu/data/`, ~2 900 строк
   с утилитами, SQLite встроена). Свой фильтр контента с таймером, срок
   хранения, очистка, миграция схемы.
10. Превью содержимого быстрых заготовок при вводе `/`
    (`chat_helpers/field_autocomplete.cpp`). Сообщения заготовок грузятся
    лениво — нужны состояния «грузится / пусто / ошибка». Ни в одном форке нет.
11. **Раздача сотрудникам**: релизные библиотеки и релизная сборка macOS,
    затем Windows (на основе `.github/workflows/win.yml`; webview там —
    WebView2), публикация в GitHub Releases.

## Риски

- api_id один на всех сотрудников.
- Без сертификатов macOS и Windows предупреждают при первом запуске
  (Apple Developer $99/год — решение отложено).
- Сотрудники не узнают об обновлениях сами — нужен баннер «вышла новая версия».
- Мобильные клиенты не покрываются.
